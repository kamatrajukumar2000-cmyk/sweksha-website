# Security Policy

SWEKSHA FOUNDATION CLUB takes the security and privacy of its website and marketplace seriously.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to:

- Email: kamatrajukumar2000@gmail.com
- Website: https://swekshacvd.com/

Please include the affected URL, a clear description, reproducible steps, and screenshots or request details where safe. Do not include customer passwords, private records, or secret API keys.

## Responsible testing

- Do not access, modify, download, or disclose another person's data.
- Do not submit spam, destructive payloads, or large-volume requests.
- Do not disrupt the website, Supabase project, marketplace, or business operations.
- Do not publicly disclose an issue until SWEKSHA has had a reasonable opportunity to investigate and address it.

## Scope

The scope includes the public website, customer enquiry forms, machine and parts marketplace, diamond trading marketplace, and administrative pages.

## Important security boundaries

- Supabase publishable/anon keys are public client identifiers, not secrets.
- Supabase service-role keys, passwords, recovery tokens, and private credentials must never be committed to this repository or embedded in browser code.
- Public submissions must remain pending until authorised admin review.
- Private customer enquiries and unpublished marketplace submissions must not be publicly readable.
- Public listing images are intended to be publicly viewable; upload, replacement, and deletion permissions must remain restricted.

This policy describes the intended handling process. It is not a claim that the website is immune to attack or that every control has already been deployed.
