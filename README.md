# Sweksha Fondation Club

This is a static website. Open `index.html` in a browser; no Node.js installation or build step is required.

## Reviews

Reviews are saved in the current browser's local storage and appear only in that browser. They are not uploaded or shared with other visitors. Clearing browser data removes locally saved reviews. The initial review list is in the `initialReviews` JSON script tag in `index.html`.

The service request form opens WhatsApp and does not store requests.
